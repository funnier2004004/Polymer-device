# L1 方法与来源

主要依据：保存在 references 中的 Practical Methods Guide，第 3 页常数和积分网格，第 4 页公式及单位，第 5 页实现、参考值和 checkpoint。Assessment Brief 第 3 页规定 L1 目标，第 5–6 页规定提交内容，第 8–9 页规定贡献和复现。已目视核对方法指南第 4 页的公式，避免纯文本提取遗漏数学符号。

## 模型

采用 g(E)=cE，f(E)=1/[exp((E-EF)/(kB*T))+1]。

- n_band = N_A * integral[0, 2.5 eV] cE f(E) dE。
- n_Fermi = N_A * integral[EF, 2.5 eV] cE f(E) dE。
- n_Fermi_closed = N_A*c*kB*T*[EF*ln(2)+(pi^2/12)*kB*T]。
- C=n_band/n_Fermi；mu=1/(e*n*rho)，n 用 cm^-2 时 mu 已为 cm^2/(V s)。

两个积分都使用有限温度，指数按老师建议截断到 [-60,60]，每次 20,001 点，用 np.trapezoid。闭式表达式对应无限上限；在本组温度和 EF 范围内，将 2.5 eV 以上尾部忽略与数值精度一致。此处的 Fermi-referenced count 是课程规定的提取模型，不能不加说明地视为所有输运模型中的通用总载流子浓度。

输入来源为 G05 的原始参数与 sweep。每次运行校验 manifest 的全部 9 个文件，输出完整 SHA-256 记录。对 CSV 点使用老师提供的 n_band，自己计算 n_Fermi；平滑曲线和交点重算两个积分。工作点从参数文件读取，不用最近表格行。

## 检查和容差

- 300 K neutrality：绝对误差不超过 1e-12。
- 0.073、0.10、0.20 eV 参考值：绝对容差 0.01。老师给的是近似值，这一容差用于参考检查，不代表评分容差。
- 数值积分对闭式：相对容差 5e-6。
- 20,001 对 40,001 网格的工作点 n 和 C：相对容差 5e-6。
- 重算 n_band 对 CSV：相对容差 1e-5，允许生成网格与四舍五入差异。
- 迁移率比值、独立 SI 单位换算和 c 消去：相对容差 1e-12。
- C=2 和 C=4 交点用 45 步二分法求解，代回绝对误差不超过 1e-10。

同时检查原始输入有限值、正值/适用域、单调性、JSON 字段和包完整性。checks.json 保存每个观测值、期望值、误差、容差与结论。

## 已发现的文件差异

Assessment Brief 第 3 页 L1 gate 写 EF=0.10 eV 时 roughly x2。Methods Guide 第 5 页及数据 README 明确给出约 2.60，0.073 eV 才约 2.00。严格按两个有限温度积分计算支持方法指南；保留这一差异，不把 2.00 作为 0.10 eV 的硬检查。主目录和学生包中两份方法指南的 L1 第 3–5 页文字已核对，关键公式、参考值和步骤一致；仓库保留学生包版本。

## 不确定性和建议边界

L1 数据没有提供 c、T、rho 的测量不确定性，不虚构置信区间。积分加密、闭式交叉检查只证明数值稳定性。更换提取模型引起的 mobility 改变不能解释为散射机制改变。Sensor advice 明确限定在其他条件固定且 sensitivity 与 1/n 成正比的模型中；不声称已验证真实器件响应。

没有访问或推测老师未发表论文，也没有给此类内容编造引文。讲义的具体模型有疑点时先记录和验证，再向老师核实。
